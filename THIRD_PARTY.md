# Attribution and dependency boundaries

## Extraction origin

The Neon adapter, sample-monitoring, marker-geometry and dwell-control concepts were extracted and
adapted from the MIT-covered portions of **Lingnan Starry Night** (2026 contributors).
The original copyright notice is retained in LICENSE. The extracted code is independently packaged;
it does not import or locate the original repository at runtime.

The original game's GazeFollower2 implementation/models, university branding, campus imagery,
participant records, private configuration and deployment material are not distributed here.

## Pupil Labs

- [pupil-labs/pl-realtime-api](https://github.com/pupil-labs/pl-realtime-api): official network client;
  optional runtime dependency, tested at 1.9.0. MIT license.
- [pupil-labs/real-time-screen-gaze](https://github.com/pupil-labs/real-time-screen-gaze): official
  AprilTag mapping and marker generator; optional runtime dependency, tested at 1.1.2. MIT license.
- [pupil-labs/gaze-controlled-cursor-demo](https://github.com/pupil-labs/gaze-controlled-cursor-demo):
  reference for marker orientation. No source files from that demo are redistributed.

The four bundled marker PNGs are generated by the official real-time-screen-gaze marker generator
using tag36h11 IDs 0–3, with both axes flipped and one cell of white quiet zone. Regeneration command:
`python tools/generate_markers.py` (requires the neon extra). The Pupil Labs MIT notice is retained in
`LICENSES/Pupil-Labs-MIT.txt`. Marker bitmap patterns are generated assets, not a new gaze algorithm.

The browser and Pygame demo visuals are simple programmatic shapes; no external fonts or game art are bundled.

## Optional packages

Pygame CE and aiohttp are installed separately as optional dependencies. Their licenses, and licenses
of SDK transitive dependencies such as AprilTag, surface-tracker, NumPy, OpenCV and PyAV, remain their
own. This repository/wheel does not vendor those dependencies or relicense them under MIT.
If distributing a frozen executable that bundles them, collect and review the licenses for that
specific bundle. The Windows lock file records versions, not a blanket license assertion.

Neon is a Pupil Labs product name. This project is unofficial and does not claim endorsement.
